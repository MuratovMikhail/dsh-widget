# DSH Widget bridge

Служебный плагин: запускает карточку [DSH Widget](../README.md) вместе с DeepSeek Harness
и закрывает её, когда плагин выгружается (выход из DSH).

Сам виджет — отдельное приложение и работает без плагина. Плагин нужен только для того,
чтобы карточка появлялась автоматически при старте DSH.

## Что делает

- при активации профиля запускает `widget-ui.ps1` (PowerShell, без окна консоли);
- при выгрузке плагина завершает дерево процессов карточки через `tools\stop-widget.ps1`;
- каталог виджета можно переопределить переменной окружения `DSH_WIDGET_DIR`,
  а для отладочного вывода — `DSH_WIDGET_DEBUG=1`.

## Ограничения

- Windows: используется `powershell.exe` и `taskkill`.
- Если карточка уже запущена, второй экземпляр молча выходит (у виджета есть мьютекс).
- В режиме плагина виджет сам завершится через 5 минут после закрытия DSH, даже если плагин
  не успел выгрузиться (`exitWhenDshClosedMin`).
